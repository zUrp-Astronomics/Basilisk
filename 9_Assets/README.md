# Ressources publiques / Public assets

`zurp.yml` est la fiche lue au build du site zUrp Astronomics. Ses identifiants, le statut, l'affiche et les licences restent régis par le contrat du site. Le catalogue n'est pas tenu à la main.

`manual/` contient les quatre onglets, chacun en `.en.md` et `.fr.md` : `overview`, `assembly`, `setup`, `usage`. Pas de H1 ni de HTML brut. Les liens entre onglets restent relatifs ; les images sont dans ce dossier. Le site ajoute l'installation et le banc issus de la release dans Setup.

Le lecteur actuel choisit EN, avec repli FR : fournir les deux fichiers n'active pas un sélecteur global. Les manuels autonomes du dépôt sont dans [7_Docs](../7_Docs/README.md).

## English

`zurp.yml` is the product sheet consumed at site build time. IDs, status, poster and licences follow the site's contract. The catalogue is generated.

`manual/` holds four tabs in both `.en.md` and `.fr.md`: `overview`, `assembly`, `setup`, `usage`. No H1 or raw HTML. Tab links stay relative; images belong in this folder. The site adds the release's installer and bench to Setup.

The current reader prefers EN and falls back to FR; paired files do not activate a global language switch. Standalone repository manuals are in [7_Docs](../7_Docs/README.md).
